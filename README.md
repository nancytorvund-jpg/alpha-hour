# Alpha Hour

A premium after-school program that runs the Alpha academic model on Timeback inside existing Alpha School buildings, for families who do not attend Alpha. It is designed to make money, use real estate Alpha already pays for, and feed full-time Alpha enrollment.

**Owner:** Nancy Wisniewski Torvund, proposed Head of Alpha Hour.

## The model in one paragraph

The accelerated Alpha experience in one focused hour, both subjects (Math and Reading/Writing), mixed K-8. Each family picks a two-night track, Monday/Wednesday or Tuesday/Thursday. Two time blocks run each evening (5:00-6:00 and 6:15-7:15), so every room serves four cohorts a week and enrolls four times its seat count. Families enroll one seven-week session at a time; there are five sessions a year. Priced above every competitor at $3,200 per session in premium markets, a fraction of full Alpha tuition.

## Headline numbers

- **East Coast premium pilot (Fall 2026)** at full capacity: 1,720 enrolled, ~$27.5M revenue, ~$22.7M net, ~$40M-$60M feeder pipeline.
- **National rollout** opens January 2027.
- **Full 40-campus network at capacity:** ~$175M revenue, ~$146M net, ~$225M-$340M feeder pipeline, which is about 0.6% of a ~$28B serviceable market. No ceiling.
